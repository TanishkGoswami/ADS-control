# UI / 02 - Dashboard View Specification

## 1. Top Header
- Global Date Range Picker (Today, Yesterday, Last 7D, MTD, Custom).
- Currency Selector (USD, INR, EUR) with live rate indicator.

## 2. Main KPI Grid
- **Aggregate Spend Today:** Large bold metric with % change vs yesterday.
- **Active Ad Accounts:** Count of green (active) vs red (disabled) accounts.
- **Client Treasury Liability:** Total cash held on behalf of clients.
- **Vendor Credit Utilization:** Progress bar showing % of credit used.

## 3. Real-time Burn Rate Chart
- Multi-series line chart displaying hourly spend curve across top 5 clients.
