# UI / 04 - Ad Account Detail View

## 1. Components
- **Account Summary Banner:** Status, Meta ID, Timezone, Currency, Bound Vendor Card.
- **Fund Allocation Control:** Quick buttons to Add Funds (+$500, +$1,000, Custom) or Return Unspent Funds.
- **Campaigns Data Table:** Searchable, sortable list with inline toggle to pause/unpause campaigns.
- **Spend vs Allocation Progress Bar:** Visual bar indicating budget depletion percentage.
