<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Browser or extension to API | Untrusted bearer tokens and request bodies enter the NestJS process. |
| API to PostgreSQL | Session and device authorization state is resolved server-side. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-01 | Spoofing | Web and extension sessions | critical | mitigate | CSPRNG tokens, SHA-256 storage, expiry, revocation, and global default-deny guard. |
| T-08-02 | Elevation of privilege | Tenant selection | critical | mitigate | Derive organization and user exclusively from the verified principal. |
| T-08-03 | Information disclosure | CORS and logs | high | mitigate | Explicit origins and token redaction tests. |
</threat_model>
