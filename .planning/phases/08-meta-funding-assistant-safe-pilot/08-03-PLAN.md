<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| Extension/web to funding controller | Page evidence and funding choices are attacker-controlled. |
| Funding service to FundLot | Concurrent reservations can create financial over-commitment. |
| API to Meta provider | External refresh may fail or return stale data. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-07 | Elevation of privilege | Funding endpoints | critical | mitigate | Principal-scoped queries, role/account access checks, negative tenant tests. |
| T-08-08 | Tampering | Reservation transaction | critical | mitigate | Transactional re-read, compound uniqueness, and concurrent integration test. |
| T-08-09 | Repudiation | Review decisions | high | mitigate | Append-only events and sanitized AuditLog actor records. |
| T-08-10 | Information disclosure | Meta verification | high | mitigate | Never serialize Meta tokens or provider URLs into errors/events. |
</threat_model>
