| Boundary | Description |
|---|---|
| Operator UI to API | User-entered amounts, reasons, filters, and identifiers are untrusted. |
| API response to browser rendering | Stored event text and error messages can contain unsafe content. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-08-14 | Tampering | Review actions | high | mitigate | API remains authoritative; UI sends IDs/reasons only and renders server result. |
| T-08-15 | Information disclosure | Pairing/device UI | high | mitigate | Never persist or redisplay claimed device credentials. |
| T-08-16 | Information disclosure | Event rendering | medium | mitigate | Render structured fields as React text; no raw HTML. |
</threat_model>
